# Comfyui-Goohai_BugFixes

一个用于修复 新版ComfyUI 前端小问题、增强组标题操作体验的轻量级补丁，不包含工作流节点，也不会影响模型推理性能。后续若有其它小bug会持续加入补丁。

## 解决的问题

- 修复工作流 JSON 无法直接拖入 ComfyUI 加载的问题。
- 修复拖入工作流 JSON 后标签不显示文件名、无法重命名的问题。
- 修复图片、视频、音频无法直接拖到官方加载节点的问题。
- 修复组标题字号改变后没有同步变化的问题。

## 支持的功能

- 图片可直接拖到 `LoadImage` 节点。
- 视频可直接拖到 `LoadVideo` 节点。
- 音频可直接拖到 `LoadAudio` 节点。
- 工作流 JSON 可直接拖到画布加载。
- 在组标题上按住鼠标右键左右滑动，可实时调整标题字号，最小 `12 px`。
- 选中多个组后，可同步调整多个组的标题字号；嵌套组只调整最外层组。
- 标题放大后，如果与下方节点或子组间距不足，会自动向上扩展并保留 `24 px` 间距。
- 支持组标题左对齐、居中和右对齐。
- 组颜色支持实时预览、63 种预设颜色和自定义取色。
- 标题文字可单独调整饱和度和明度，色相自动跟随组颜色。
- 更改组颜色后，标题文字会自动切换到相同色相。
- 标题字号、对齐方式和标题颜色设置会随工作流保存。

## 安装

将整个 `Comfyui-Goohai_BugFixes` 文件夹放入：

```text
ComfyUI/custom_nodes/
```

重启 ComfyUI即可。
